# Sandy Show Miami

Repositorio web oficial de **MSc. Sandy Fernández Fernández — Sandy Show Miami**.

## Objetivo
Centralizar la presencia digital oficial de Sandy Show Miami: biografía, Lo de Nosotros No Tiene Nombre, música, galería y libros con enlaces de compra en Amazon y Apple Books.

## Estructura
- `index.html` — portada y entidad principal
- `biografia.html` — biografía
- `programa.html` — Lo de Nosotros No Tiene Nombre
- `libro.html` — biblioteca oficial
- `musica.html` — música
- `galeria.html` — galería
- páginas individuales de libros
- `sitemap.xml`, `robots.txt` — indexación
- JSON-LD Schema.org en páginas principales — entidad, podcast y libros
- `_headers` — cabeceras compatibles con Cloudflare Pages

## Publicación
El repositorio está preparado para conectarse a Cloudflare Pages. El dominio en producción no debe cambiar hasta verificar una vista previa del despliegue.

## Principio SEO
Usar de forma natural y consistente los nombres **Sandy Show Miami**, **Sandy Fernández Fernández** y **Lo de Nosotros No Tiene Nombre**, evitando relleno de palabras clave o prácticas engañosas.
